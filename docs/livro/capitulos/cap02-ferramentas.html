Detalhes que pegam
  • O buildah mudou de endereço: o repositório é github.com/containers/buildah, mas o módulo Go é go.podman.io/buildah. Confira sempre a primeira linha do go.mod do repo.
  • O módulo do Gitleaks ainda é github.com/zricethezav/gitleaks/v8, apesar de o repositório ter mudado.
  • O Grype está em v0.x: a API pode quebrar em qualquer versão menor (cap. 20).
  • O banco de CVEs do Grype é um arquivo à parte, baixado em tempo de execução de grype.anchore.io. Sem internet, use --skip-cves ou um mirror interno.
