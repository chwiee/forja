Catálogo de erros

Todos os erros abaixo aconteceram de verdade na construção do forja. Quando algo quebrar, procure aqui pela mensagem (Ctrl+F) antes de qualquer outra coisa. O método de investigação é quase sempre o mesmo do capítulo 8: copie um trecho da mensagem, ache com git grep o código que a gera, leia a condição.
