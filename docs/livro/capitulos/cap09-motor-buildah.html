9.2 A implementação real (só Linux)

Repare nas escolhas de BuildOptions. Cada uma resolve um problema do capítulo 10: IsolationChroot dispensa o runc, NamespaceOptions + NetworkInterface dispensam o netavark. Com Platforms preenchido, o build vira multi-arch e gera um manifest list; o Push detecta isso e publica todas as arquiteturas (capítulo 16). O systemContext usa a configuração embutida do capítulo 13.

9.3 A rede "de mentira"

O buildah exige uma implementação da interface ContainerNetwork (13 métodos), mesmo quando os RUN usam a rede do host. Implementar a interface inteira, com erros claros, é mais seguro do que embutir a interface num struct e torcer para os métodos não chamados nunca serem usados (isso daria panic). A linha var _ nettypes.ContainerNetwork = hostNetwork{} faz o compilador conferir o contrato.
