9.3 A rede "de mentira"

O buildah exige uma implementação da interface ContainerNetwork (13 métodos), mesmo quando os RUN usam a rede do host. Implementar a interface inteira, com erros claros, é mais seguro do que embutir a interface num struct e torcer para os métodos não chamados nunca serem usados (isso daria panic). A linha var _ nettypes.ContainerNetwork = hostNetwork{} faz o compilador conferir o contrato.

9.4 Só Linux, por decisão

O forja roda só em pods Linux. Por isso o pacote build tem o contrato em build.go (tipos e a interface Engine, que compilam em qualquer sistema) e o motor em build_linux.go. O main.go começa com //go:build linux: fora do Linux, o go build para com build constraints exclude all Go files. Os testes da CLI usam um Engine falso, então continuam rodando no Windows.

Até a v0.4.1 havia um build_other.go (//go:build !linux) com métodos que só devolviam erro, para gerar um forja.exe com exists e inspect. Como o forja não roda em Windows, ele foi removido. Um teste mostrou o que ele segurava: sem ele, o main.go não compila no Windows (undefined: build.InitReexec), enquanto os testes da CLI passam. É o tipo de quebra que só o go build pega.
