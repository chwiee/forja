Arquitetura: um binário, três lugares

O forja é um único binário Linux estático que traz o código do buildah compilado dentro. Ele é publicado numa imagem distroless multi-arch e pode ser copiado para qualquer outra imagem; em todos os ambientes, é o mesmo binário.

O que acontece num forja build --push

  1. Lê o Dockerfile do usuário, montado em /workspace. O forja não sabe nada da aplicação; ele recebe um diretório com um Dockerfile.
  2. Baixa a imagem base do FROM, conferindo a política de /etc/containers/policy.json.
  3. Executa cada RUN num chroot. O isolamento é código Go do próprio buildah, sem runc nem crun, e usa a rede do container do forja.
  4. Grava as camadas no storage local (/var/lib/containers).
  5. Publica com buildah.Push e devolve o digest. O --immutable recusa sobrescrever uma tag existente.

O que o forja exige do ambiente testado
